## 2.4.1

- Switch Vision Settings now uses top tabs for UI, Discovery and SNMP2MQTT sections.
- Dashboard Card YAML can be regenerated directly from current saved device state, including immediately after enabling/disabling a device, without a new Discovery run or SNMP walks.
- Detailed detected-device information now expands inline on Devices; the duplicate standalone diagnostics card/page is removed while Copy/Download Diagnostics remains available.
- SNMP2MQTT handoff verification now uses exact generated-config identity rather than asynchronous retained MQTT entity counts, preventing false Discovery failures during publication catch-up.
- WS-C3850-12XS-E keeps its Experimental 0-RJ45 / 12-SFP physical contract while its visual metadata aligns with Core's 2048 x 448 owner-supplied geometry.
